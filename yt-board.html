設定

    APIキーの作り方（初回だけ・無料）
    1. Google Cloud コンソールでプロジェクトを作る（名前は何でも可）
    2. YouTube Data API v3 を開き「有効にする」
    3. 認証情報 →「認証情報を作成」→「APIキー」
    4. 作ったキーの編集画面で制限をかける（他人に使われないため）
      ・アプリケーションの制限：ウェブサイト → https://architraveaaa.github.io/*
      ・APIの制限：YouTube Data API v3 のみ
    5. キーを上の欄に貼る
    キーはこのブラウザの中だけに保存され、YouTube（Google）以外には送られません。読めるのは公開・限定公開の再生リストです。
